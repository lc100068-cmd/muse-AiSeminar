## レイアウトの型

- 比較は左右2分割。
- 説明は番号・短文・イラストを組み合わせる。
- ページ下部に要点を置く。
- ワークは大きな文字と絵で呼びかける。
- 説明ページと問いかけ・体験ページを交互に入れる。

## 強みと調整点

難しいテーマに入りやすく、絵と具体例で記憶に残る。一方、元資料の一部は情報と装飾が密集し、会場後方から細部を追いにくい。今回のMuse資料では一枚の文字量を減らし、説明と具体例を分けた。手描き・水彩・写真などが混在する元資料の幅を踏まえ、今回はノート背景と水彩風の挿絵で統一した。
