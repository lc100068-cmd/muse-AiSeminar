# 作成の経緯

## ユーザーの依頼

1. 提供した2つのPDFのスライドの雰囲気を分析する。
2. 両資料に共通する特徴をまとめる。
3. MetaのMuseについて、YouTube投稿を起点に基本機能とビジネス活用を調べる。
4. 分析した雰囲気と調査内容を踏まえてスライドを作る。
5. ここまでの情報を `muse-AiSeminar` リポジトリに格納する。

## 完成物

日本語の21枚構成。基本機能、アプリ連携、メール・DM、商談準備、SNS、画像・動画、定期タスク、Spaces、経費整理、権限と役割分担、依頼文、体験ワーク、出典を収録。

チャットでは編集可能なライブスライドとして作成した。このリポジトリには、同内容を持ち出せるPowerPoint、閲覧用PDF、全ページのプレビュー、内容データ、講師用ノートと原稿を保存している。
